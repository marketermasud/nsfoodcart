# NS Food Cart — অনলাইন অর্ডার ওয়েবসাইট + অ্যাডমিন অ্যাপ

স্ট্যাটিক HTML সাইট (GitHub Pages-এ চলে), ডেটাবেস হিসেবে Firebase।

| ফাইল | কাজ |
|---|---|
| `index.html` | কাস্টমারের ওয়েবসাইট: মেনু, কার্ট, অর্ডার, অর্ডার ট্র্যাকিং |
| `admin.html` | অ্যাডমিন প্যানেল (হোম স্ক্রিনে ইনস্টল করা যায়) |
| `js/firebase-config.js` | **শুধু এই ফাইলে** Firebase কনফিগ বসাতে হবে |
| `js/store.js` | ডেটা লেয়ার (Firebase / ডেমো মোড) |
| `firestore.rules` | Firestore সিকিউরিটি রুলস |
| `manifest.webmanifest`, `sw.js`, `icons/` | অ্যাডমিন অ্যাপ ইনস্টলের জন্য |

## Firebase (কনফিগ বসানো আছে: প্রজেক্ট `nsfoodcart`)

`js/firebase-config.js`-এ কনফিগ বসানো আছে। Firebase Console-এ একবার এই কাজগুলো করতে হবে:

1. **Build → Firestore Database → Create database** (production mode)।
2. **Build → Authentication → Sign-in method → Email/Password** চালু করুন। তারপর **Users → Add user** দিয়ে অ্যাডমিনের ইমেইল ও পাসওয়ার্ড বানান। এটাই অ্যাডমিন লগইন।
3. `firestore.rules` খুলে `ADMIN_EMAIL_HERE@gmail.com`-এর জায়গায় ২ নম্বর ধাপের ইমেইল লিখুন। পুরো ফাইলটা **Firestore → Rules**-এ পেস্ট করে **Publish** করুন।
4. **Authentication → Settings → Authorized domains**-এ সাইটের ডোমেইন যোগ করুন (যেমন `username.github.io`)।
5. `admin.html`-এ লগইন করুন। ডেটাবেস খালি থাকলে মেনুর ১৬টি আইটেম ও ৪টি ক্যাটাগরি নিজে থেকে Firestore-এ সেভ হয়ে যাবে; এরপর ইচ্ছামতো এডিট করুন।

অ্যাডমিন লগইনের আগেও ওয়েবসাইটে একই মেনু দেখায়, তাই কানেক্ট করার পর মেনু হারায় না। ডেমো মোডে ব্রাউজারে যা বদলেছিলেন (ছবি, নতুন আইটেম, অর্ডার) তা Firebase-এ আসে না।

## GitHub Pages-এ তোলা

1. নতুন রিপোজিটরি বানিয়ে এই ফোল্ডারের সব ফাইল আপলোড করুন (`index.html` যেন রুটে থাকে)।
2. **Settings → Pages → Branch: main / root → Save**।
3. সাইট: `https://username.github.io/repo/`, অ্যাডমিন: `https://username.github.io/repo/admin.html`

## অ্যাডমিন অ্যাপ ফোনে ইনস্টল

- Android (Chrome): `admin.html` খুলুন → ওপরে **ইনস্টল** বাটন, অথবা মেনু (⋮) → **Add to Home screen / Install app**।
- iPhone (Safari): Share → **Add to Home Screen**।
- নতুন অর্ডার এলে শব্দ + নোটিফিকেশন পেতে অ্যাপ খোলা রাখতে হবে (সেটিংস থেকে নোটিফিকেশন চালু করুন)।

## যা জানা দরকার

- **অর্ডার নম্বর**: প্রতিটি অর্ডারে `NS-123456` ধরনের নম্বর তৈরি হয়। কাস্টমার এটা দিয়ে ট্র্যাক করে; ট্র্যাকিং লিংক: `index.html?order=NS-123456`।
- **গোপনীয়তা**: কাস্টমারের নাম, ফোন, ঠিকানা থাকে `orders` কালেকশনে, যা শুধু অ্যাডমিন পড়তে পারে। ট্র্যাকিং পেজ পড়ে `tracking` কালেকশন, যেখানে ব্যক্তিগত তথ্য নেই।
- **অ্যাডমিন থেকে অর্ডার**: অর্ডার ট্যাবে **নতুন অর্ডার** দিয়ে ফোনে আসা অর্ডার তোলা যায়; প্রতিটি চলমান অর্ডারে **আইটেম যোগ/বদল** দিয়ে আইটেম বাড়ানো-কমানো যায়।
- **ডিফল্ট স্লাইড**: Unsplash-এর তিনটি ফ্রি ছবি সরাসরি লিংক করা (Mario Raj, Clem Onojeghuo, Georgii Eletskikh)। নিজের ছবি আপলোড করলে এগুলো সরে যায়।
- **রিভিউ**: ওয়েবসাইটে কোনো আইটেমে চাপ দিলে সেটার পাতা খোলে, সেখানে নাম, তারা আর মতামত দিয়ে রিভিউ দেওয়া যায়। রিভিউ থাকে `reviews` কালেকশনে; কাস্টমার এডিট বা ডিলিট করতে পারে না, শুধু অ্যাডমিন পারে (অ্যাডমিন → রিভিউ)। একই ব্রাউজার থেকে এক আইটেমে একবারই রিভিউ দেওয়া যায়।
- **কাস্টমারের ইতিহাস**: অ্যাডমিনে প্রতিটি অর্ডারে একই ফোন নম্বরের আগের অর্ডার, সফল ডেলিভারির হার (%) আর বাতিলের কারণ দেখায়। অর্ডার ট্যাবের সার্চ বক্সে ফোন নম্বর, নাম বা অর্ডার নম্বর দিয়ে খোঁজা যায়।
- **বাতিলের কারণ**: বাতিল করার সময় কারণ বেছে নিতে হয়। কাস্টমারের কারণে বাতিল হলে তার স্কোর কমে, দোকানের কারণে হলে কমে না।
- **অনুষ্ঠানের অর্ডার**: ওয়েবসাইটে মেনুর নিচের "অনুষ্ঠানের অর্ডার দিন" থেকে আইটেম, প্যাকেটের সংখ্যা আর তারিখ দিয়ে আগাম অর্ডার দেওয়া যায়; অ্যাডমিনে বেগুনি চিহ্নসহ দেখায়।
- **সময় ধরে ফ্রি ডেলিভারি**: অ্যাডমিন → সেটিংস → অর্ডার ও ডেলিভারি অংশে শুরু ও শেষ সময় দিলে ওই সময়ে ডেলিভারি ফ্রি থাকে; শেষ সময় পার হলে চার্জ নিজে থেকে ফিরে আসে।
- **স্লাইড ছবি**: সেটিংস → হোমপেজের স্লাইড ছবি থেকে সর্বোচ্চ ৬টি ছবি দেওয়া যায়; না দিলে আঁকা ছবি দেখায়।
- **ছবি**: আপলোড করা ছবি ছোট করে সরাসরি Firestore-এ রাখা হয়, তাই Firebase Storage (পেইড প্ল্যান) লাগে না।
- **পেমেন্ট**: ক্যাশ অন ডেলিভারি। সেটিংসে বিকাশ নম্বর দিলে চেকআউটে দেখাবে; অনলাইন পেমেন্ট গেটওয়ে নেই।
- **"এই মুহূর্তে চলছে"**: ক্যাটাগরিতে সময় (ঘণ্টা) দিলে ওই সময়ে হোমপেজের বোর্ডে সেই ক্যাটাগরি দেখায়।
